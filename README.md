# TASK-15
JavaScript - Arrays and Functions

Objective

Create JavaScript functions that perform different operations on an array.

Operations Performed

- Find the maximum number in the array.
- Calculate the sum of all elements.
- Count the number of odd numbers.
- Use different types of functions.
- Display the results using "console.log()".

Example Array

[4, 8, 2, 11, 6, 7, 10]

Example Output

Array: [4, 8, 2, 11, 6, 7, 10]
Maximum number: 11
Sum of all elements: 48
Count of odd numbers: 2

Functions Used

- Arrow Function - Find maximum number
- Anonymous Function - Calculate sum
- Normal Function - Count odd numbers

How to Run

1. Open the project folder in VS Code.
2. Open "index.html" in the browser.
3. Open Browser Console using "F12".
4. Check the output in the Console.
